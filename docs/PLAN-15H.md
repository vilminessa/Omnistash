  отдают `X-Frame-Options`/CSP, поэтому встроенный `<iframe>` не загрузит

- GitHub: в этом окне пуш только в Forgejo (`origin`); GitHub — после
  ручных тестов и правок человека.
- Релизный тег и сборка exe: в конце окна, без тега (`b0.2.0` позже).
- Сеть: живые пробы разрешены (YouTube, RSS, списки страниц площадок).
  Страницы видео взрослой площадки из этой сети блокируются — одна проба,
