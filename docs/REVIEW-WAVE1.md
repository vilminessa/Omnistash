# Ревью волны 1 (основное дерево)

Ревью read-only по коду после сводок волны 1: `main` = `c622489`,
merge-коммиты `7177327` (M17 массовые операции), `9982c38` (E0 аудио),
`bb28340` (M13 цепочка дорог выкачки). Полный набор в тот момент:
910 тестов OK (17 skipped). Ревью-агент не имел shell, поэтому сверял
файлы по HEAD, а не по diff-ам сводок; находки перепроверены оркестратором
по строкам кода.

Правило применения: находки правятся **после** сводки волны 2 (агенты
`themes` и `browser` сейчас владеют `app/settings_schema.py`, `app/gui.py`,
`ui_src/*`), отдельными коммитами, каждый — с прогоном набора.
