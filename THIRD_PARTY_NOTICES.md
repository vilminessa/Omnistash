# Третьи стороны

Сам Omnistash стороннего кода не содержит: всё, что в репозитории,
написано для этого проекта. Один инструмент проект использует, но
**не поставляет и не распространяет** — и это намеренно.

## zeroconf (опционально, не поставляется)

- **Что это**: python-zeroconf (https://github.com/python-zeroconf/
  python-zeroconf) — реализация mDNS/DNS-SD для обнаружения участников
  в локальной сети (этап B4). Лицензия — LGPL-2.1+, она несовместима с
  PolyForm Noncommercial при встраивании в exe, поэтому библиотека **не
  входит ни в исходники-зависимости, ни в сборку**.
- **Как попадает к пользователю**: только по его инициативе —
  `pip install zeroconf`. Без неё программа работает полностью:
  обнаружение идёт старыми способами (LAN-приветствие, DHT, ручные
  адреса), а строка в журнале честно пишет, почему mDNS выключен.
- **Что именно используется**: объявление сервиса `_omnistash._tcp`
  (адрес, порт, ник в TXT) и поиск таких сервисов; модуль
  `app/mesh/mdns.py` подключает библиотеку лениво (импорт в try).

## ffmpeg

- **Что это**: ffmpeg (https://ffmpeg.org) — консольный инструмент для
  склейки, метаданных, субтитров и перекодировки. Лицензия сборки —
  GPL v2+ (нам она несовместима с PolyForm Noncommercial, поэтому
  ffmpeg не входит ни в исходники, ни в exe и не попадает ни в один
  релиз).
- **Как попадает к пользователю**: только по его инициативе — кнопка
  «Скачать ffmpeg» в настройках (раздел «Загрузка»), после явного
  согласия в диалоге. Скачивание идёт напрямую с серверов билдера, мимо
  нас:
  - основной источник — gyan.dev, `ffmpeg-release-essentials.zip`;
  - зеркало — BtbN/FFmpeg-Builds на GitHub, `ffmpeg-master-latest-win64-gpl.zip`.
- **Что именно ставится**: из архива берутся только `ffmpeg.exe` и
  `ffprobe.exe` — в `%LOCALAPPDATA%\Omnistash\bin`. Удаление этой папки
  полностью удаляет ffmpeg.
- **Проверка перед подменой**: свежий бинарник пробуется запустить
  (`ffmpeg -version`); не запустился — файл не подменяется.

Проект не аффилирован с ffmpeg и с билдерами gyan.dev/BtbN. За саму
программу и соблюдение её лицензии отвечает тот, кто её скачал.
