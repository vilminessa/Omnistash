# Третьи стороны

Этот файл — полный список сторонних компонентов Omnistash: что входит в
сборку, что ставится пользователем и что используется как внешняя
инфраструктура. Состав собран по фактическому содержимому `Omnistash.exe`
(сборка PyInstaller) — не по списку зависимостей, а по распаковке самого
exe.

Три группы:

1. **Входит в Omnistash.exe** — распространяется вместе с программой,
   уведомления здесь обязательны для каждого, кто распространяет сборку.
2. **Ставится пользователем отдельно** — проект не поставляет и не
   распространяет эти компоненты вместе с собой.
3. **Внешняя инфраструктура** — используется через сеть, на условиях
   её владельцев.

### Microsoft WebView2

Пакет pywebview поставляет с собой `WebView2Loader.dll`,
`Microsoft.Web.WebView2.Core.dll` и `Microsoft.Web.WebView2.WinForms.dll`
(компоненты Microsoft) — они распространяются на условиях Microsoft для
WebView2, а не на условиях проекта. Сама среда выполнения WebView2
(Evergreen) — часть Windows 11 / устанавливается Microsoft; проект её не
поставляет.

## 2. Ставится пользователем отдельно (проект не поставляет)

### ffmpeg (GPL v2+)

- **Что это**: ffmpeg (https://ffmpeg.org) — консольный инструмент для
  склейки, метаданных, субтитров и перекодировки. Лицензия сборки —
  GPL v2+ (несовместима с PolyForm Noncommercial при встраивании,
  поэтому ffmpeg не входит ни в исходники, ни в exe, ни в один релиз).
- **Как попадает к пользователю**: только по его инициативе — кнопка
  «Скачать ffmpeg» в настройках (раздел «Загрузка»), после явного
  согласия в диалоге. Скачивание идёт напрямую с серверов билдера, мимо
  нас:
  - основной источник — gyan.dev, `ffmpeg-release-essentials.zip`;
  - зеркало — BtbN/FFmpeg-Builds на GitHub, `ffmpeg-master-latest-win64-gpl.zip`.
- **Что именно ставится**: из архива берутся только `ffmpeg.exe` и
  `ffprobe.exe` — в `%LOCALAPPDATA%\Omnistash\bin`. Удаление этой папки
  полностью удаляет ffmpeg.
- **Проверка перед подменой**: свежий бинарник пробуется запустить
  (`ffmpeg -version`); не запустился — файл не подменяется.

Проект не аффилирован с ffmpeg и с билдерами gyan.dev/BtbN. За саму
программу и соблюдение её лицензии отвечает тот, кто её скачал: если
вы распространяете ffmpeg — распространяйте с его лицензией.

### zeroconf (LGPL-2.1+, опционально)

- **Что это**: python-zeroconf (https://github.com/python-zeroconf/
  python-zeroconf) — реализация mDNS/DNS-SD для обнаружения участников
  в локальной сети (этап B4). Лицензия — LGPL-2.1+, она несовместима с
  PolyForm Noncommercial при встраивании в exe, поэтому библиотека **не
  входит ни в исходники-зависимости, ни в сборку**.
- **Как попадает к пользователю**: только по его инициативе —
  `pip install zeroconf`. Без неё программа работает полностью:
  обнаружение идёт старыми способами (LAN-приветствие, DHT, ручные
  адреса), а строка в журнале честно пишет, почему mDNS выключен.
- **Что именно используется**: объявление сервиса `_omnistash._tcp`
  (адрес, порт, ник в TXT) и поиск таких сервисов; модуль
  `app/mesh/mdns.py` подключает библиотеку лениво (импорт в try).

### magic-wormhole (MIT, опционально)

- **Что это**: magic-wormhole (https://github.com/magic-wormhole/
  magic-wormhole) — разовая передача по короткому коду (PAKE → E2E),
  этап B1. Лицензия — MIT.
- **Как попадает к пользователю**: только по его команде — функции
  `python -m app.wormhole setup` или кнопка в диалоге «Участники»;
  библиотека ставится pip'ом в **изолированный venv внутри профиля**
  (`%LOCALAPPDATA%\Omnistash\wormhole-venv`), в зависимости проекта не
  входит и в exe не входит. Удаление папки venv удаляет всё.
- Ставятся и транзитивные зависимости wormhole (Twisted, PyNaCl и
  другие) — они остаются в venv и не покидают его.

## 3. Внешняя инфраструктура (на условиях владельцев)

- **Публичные bootstrap-роутеры BitTorrent DHT** (`router.bittorrent.com`
  и компания) — используются как открытая инфраструктура для
  самопоиска участников (BEP5). Проект не аффилирован с владельцами
  этих роутеров; свой IP и хеш ника при включённом участии видят все,
  кто слушает эту сеть (см. раздел «Приватность» в README).
- **Транзит-релеи magic-wormhole** — используются, только если вы
  запустили wormhole; на условиях их владельцев.
- **UPnP-роутер** — проброс порта делается вашим собственным роутером,
  на условиях его производителя.
- **YouTube / Google** — работа с площадкой идёт на условиях самой
  площадки; проект не аффилирован с Google и YouTube.
