# Участие в разработке

Клонируйте, правьте, присылайте pull request — проект приветствует
вклады. Здесь — два правила, которые важнее кода: под какой лицензией
ваш вклад попадает в проект и что делать с ИИ-генерированным кодом.

## Техническая часть

```powershell
python -m unittest discover -t . -s tests    # офлайн, 500+ проверок
```

- ветка от `main`, в одном PR — одна тема;
- тесты обязательны для исправлений багов (тест, который ловит баг, —
  лучшая часть PR);
- стиль — как в соседнем коде; проект не использует форматтер по команде.

## Лицензия вашего вклада

Проект распространяется по PolyForm Noncommercial 1.0.0, и в нём
работает двойное лицензирование: автор вправе выдать коммерческую
лицензию на тот же код. Чтобы это оставалось возможным, отправляя pull
request, вы подтверждаете и соглашаетесь на следующее:

1. Вы обладаете правами на свой вклад (это ваша работа или работа,
   сделанная вами по договору/под вашей ответственностью).
2. Вы предоставляете автору проекта (vilminessa) бессрочную, всемирную,
   безвозмездную лицензию на ваш вклад: использовать, изменять,
   включать в проект и распространять его — на условиях PolyForm
   Noncommercial 1.0.0 **и на любых других условиях, включая
   коммерческие** (право выдачи отдельных коммерческих лицензий).
3. Ваш вклад остаётся подписан вами (авторство — ваше); сам вклад
   входит в проект под PolyForm Noncommercial 1.0.0.
4. Вы не отзываете эту лицензию: отзовёшь — проект не сможет
   использовать ваш вклад, а мы не сможем гарантировать, что его ещё
   можно удалить из истории.

Если вам не подходит пункт 2 (передать право коммерческого
лицензирования) — напишите об этом **до** PR: можно вложить правку
договорённым другим способом (вручную, с явным согласием). Молча
отправленный PR означает согласие.

Это не CLA-бумага и не юридический блок для разработчиков: обычный
PR от частного лица закрывает пункт своим отправлением.

## ИИ-генерированный вклад

Проект честно вайбкод-проект: основной код пишется и эволюционируется
LLM-моделью. Отношение к этому такое:

- вклад, созданный или дописанный с помощью ИИ, проверяет и подписывает
  **отправитель** — человек (или агент, действующий по указанию
  человека);
- в PR напишите коротко, что вклад создан с участием ИИ (это не
  минус, это факт, который нам нужно знать);
- ответственность за то, что вклад не нарушает чужие права, — на
  отправителе. Не вставляйте чужой закрытый код, тексты, модели и
  ассеты «как есть» — скопированное из чужого источника остаётся
  чужым независимо от того, кто его вставил;
- юридические формулировки (лицензии, дисклеймеры, README-секции)
  правьте с пониманием последствий: спорные места лучше сначала
  обсудить в issue.

## Что согласуется заранее

Не присылайте молча PR, который меняет:

- `LICENSE`, `THIRD_PARTY_NOTICES.md`, `docs/ACCEPTABLE_USE.md`,
  `docs/LEGAL_FAQ.md` и правовой раздел README — это юридическая часть
  проекта, обсуждается в issue;
- способ сборки exe (`Omnistash.spec`, состав зависимостей) — это меняет
  состав сторонних компонентов в сборке (см. THIRD_PARTY_NOTICES.md);
- политику relay и лимиты по умолчанию — это ответственность
  участников.

## Приватность в коммитах

Не кладите в репозиторий личное: куки, ключи, куки-токены, реальные
адреса и отпечатки ваших машин, токены каналов связи. Всё это живёт
в профиле, а не в git.
