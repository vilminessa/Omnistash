# ui_flutter - Flutter-оболочка Omnistash (W0: измерительный стенд)

Здесь живёт Flutter-оболочка поверх того же Python-бэкенда. План волн и
решения человека - `docs/FLUTTER-TRANSITION.md`; система иконок и палитра
бренда - `docs/ICONS.md`.

**Что сейчас в этом каталоге (W0, spike):**

- `lib/main.dart` - окно с виртуализированным списком (2000 строк),
  автопрокруткой и замером: время до первого кадра, частота кадров, латентность
  каждой цели фасада, отказ называется текстом сервера; статистика печатается
  одной строкой `SPIKE_STATS` в stdout, её собирает
  `build/scratch/spike/measure.py` и `build/scratch/spike/live_serve.py`.
  Это измерительный стенд, не экран программы; производственные экраны
  пишутся на волне W2.
- `lib/api_client.dart` - транспорт к `--serve`: `POST /api/<имя>`, тело `{}`
  когда аргумента нет и `[аргумент]` когда есть (как `ui_src/app.js:547`),
  заголовок `Bearer`, доверие TLS по сверке отпечатка DER-сертификата с
  пином; несовпадение отвергается с названной причиной и не молчит.
- `test/widget_test.dart` - smoke-тест: окно строится без сервера и список
  виртуализуется.

**W1 - токены темы (палитра, метрики, контраст):**

- `lib/theme_tokens.dart` - сгенерированные токены: роли цвета каждой темы
  реестра `app/themes.py` (28 ролей), метрики из блока `:root` в
  `ui_src/app.css` (40 чисел: шаг отступов, радиусы, цели и контролы,
  типографика, длительности и кривые движения, две ширины кольца фокуса),
  границы шрифта и формула
  высоты строки из констант `app/themes.py`, пары контраста из
  `themes.CONTRAST_PAIRS` и перенесённая формула WCAG (`luminance`,
  `contrast_ratio`). Не править руками:
  `python tools/build_flutter_theme.py --check` сверяет ассет с генерацией
  байт-в-байт, а `python tools/check_flutter_mirror.py` сверяет его с реестром
  тем, с `:root`, со списком тем в настройках, с `LIST_COLS`/`ORDER_COLS` грида,
  с рядом целей `sel-bar`, с проводками `bulk_*` из `app/gui.py` и с механизмом
  диалога §3.8 - этот страж гоняется и в CI, где Flutter не запускается
  (`tests/test_flutter_mirror.py`, 94 проверок).
- `lib/theme.dart` - `ThemeData` из токенов: соответствие ролей на Material
  названо в комментариях файла (Material не «угадывает» роль), ни
  hex-литералов, ни размеров и длительностей числом - их запрещает
  mirror-страж.
- `test/theme_test.dart` - сверка на стороне Flutter: контрастные пары
  выдержаны для всех тем реестра, подложка окна, разделитель и граница
  контрола читаются из ролей, яркость совпадает с флагом `dark`, битое
  значение настройки возвращает дефолтную тему, типографика и радиусы читают
  метрики, высота строки списка растёт с текстом и не мельчает.

Стенд переключает тему переменной окружения, чтобы мерить обе палитры одним
бинарем: `OMNISTASH_SPIKE_THEME` (id темы из реестра, битое значение ->
дефолт) и `OMNISTASH_SPIKE_ROW_EXTENT` (высота ряда: W0 мерялась с 44 px, и
числа в `docs/FLUTTER-TRANSITION.md §9` описывают именно этот geometry;
формула токенов `rowHeight` переснимается на волне W2 вместе со списком
программы).
