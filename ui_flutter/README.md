# ui_flutter - Flutter-оболочка Omnistash (W0: измерительный стенд)

Здесь живёт Flutter-оболочка поверх того же Python-бэкенда. План волн и
решения человека - `docs/FLUTTER-TRANSITION.md`; система иконок и палитра
бренда - `docs/ICONS.md`.

**Что сейчас в этом каталоге (W0, spike):**

- `lib/main.dart` - окно с виртуализированным списком (2000 строк),
  автопрокруткой и замером: время до первого кадра, частота кадров, латентность
  каждой цели фасада, отказ называется текстом сервера; статистика печатается
  одной строкой `SPIKE_STATS` в stdout, её собирает
  `build/scratch/spike/measure.py` и `build/scratch/spike/live_serve.py`.
  Это измерительный стенд, не экран программы; производственные экраны
  пишутся на волне W2.
- `lib/api_client.dart` - транспорт к `--serve`: `POST /api/<имя>`, тело `{}`
  когда аргумента нет и `[аргумент]` когда есть (как `ui_src/app.js:547`),
  заголовок `Bearer`, доверие TLS по сверке отпечатка DER-сертификата с
  пином; несовпадение отвергается с названной причиной и не молчит.
- `test/widget_test.dart` - smoke-тест: окно строится без сервера и список
  виртуализуется.

**W1 - токены темы (палитра, метрики, контраст):**

- `lib/theme_tokens.dart` - сгенерированные токены: роли цвета каждой темы
  реестра `app/themes.py` (28 ролей), метрики из блока `:root` в
  `ui_src/app.css` (38 чисел: шаг отступов, радиусы, цели и контролы,
  типографика, длительности и кривые движения), границы шрифта и формула
  высоты строки из констант `app/themes.py`, пары контраста из
  `themes.CONTRAST_PAIRS` и перенесённая формула WCAG (`luminance`,
  `contrast_ratio`). Не править руками:
  `python tools/build_flutter_theme.py --check` сверяет ассет с генерацией
  байт-в-байт, а `python tools/check_flutter_mirror.py` сверяет его с реестром
  тем, с `:root` и со списком тем в настройках - этот страж гоняется и в CI,
  где Flutter не запускается (`tests/test_flutter_mirror.py`, 13 проверок).
- `lib/theme.dart` - `ThemeData` из токенов: соответствие ролей на Material
  названо в комментариях файла (Material не «угадывает» роль), ни
  hex-литералов, ни размеров и длительностей числом - их запрещает
  mirror-страж.
- `test/theme_test.dart` - сверка на стороне Flutter: контрастные пары
  выдержаны для всех тем реестра, подложка окна, разделитель и граница
  контрола читаются из ролей, яркость совпадает с флагом `dark`, битое
  значение настройки возвращает дефолтную тему, типографика и радиусы читают
  метрики, высота строки списка растёт с текстом и не мельчает.

Стенд переключает тему переменной окружения, чтобы мерить обе палитры одним
бинарем: `OMNISTASH_SPIKE_THEME` (id темы из реестра, битое значение ->
дефолт) и `OMNISTASH_SPIKE_ROW_EXTENT` (высота ряда: W0 мерялась с 44 px, и
числа в `docs/FLUTTER-TRANSITION.md §9` описывают именно этот geometry;
формула токенов `rowHeight` переснимается на волне W2 вместе со списком
программы).

**W2, шаг 1 - экран библиотеки из живого фасада:**

- `lib/app.dart` - `OmnistashApp`: читает `get_initial` (настройки бэкенда),
  применяет выбранную тему и размер текста из настройки (`settings.theme`,
  `settings.font_size`) - выбор человека «две темы, выбор в настройках»;
  без адреса, ключа и пина экран называет причину («сервер не запущен:
  `--serve` не поднят»), а не показывает пустой список.
- `lib/library_view.dart` - список строк через `list_videos` (ответ
  `{"total","rows"}` из `app/repo.py`), страница `kPageLimit` = `PAGE` из
  `ui_src/app.js`, опрос состояния `kPollIntervalMs` = `POLL_MS` там же,
  высота ряда из формулы токенов `rowHeight`, цвета статусов из карты
  `kStatusRoles` (тот же источник, что `.status[data-s=...]` в `app.css`).
  Семантика: строка названа целиком (имя, статус, канал, длительность,
  рейтинг, наличие обложки), выбор передаётся `selected`, строка доступна с
  клавиатуры (`ListTile` с `onTap`), полоса состояния - живый регион
  (`liveRegion`, эквивалент `aria-live`), счётчик строк табличный
  (эквивалент `--nums`). Отказ фасада внутри 200 показывается текстом
  причины.
- `test/library_view_test.dart` - 9 проверок экрана на подменёном фасаде:
  строки и подписи статуса, тема из настройки, цвет статуса из роли токенов,
  высота ряда из формулы, границы размера текста из `kFontBounds`, отказ
  назван, вторая страница грузится с `offset`, семантика строки и выбор,
  живый регион, экран без сервера называет причину.
- `main.dart` - `OMNISTASH_SPIKE=1` запускает стенд W0, без флага -
  производственный экран. Стенд печатает `SPIKE_STATS`, экран - нет;
  `build/scratch/spike/live_serve.py --production` сверяет это фактом прогона
  против живого `--serve` (какие методы пишет журнал аудита).

**W2, шаг 2 - табы и сортировка колонок:**

- `lib/tabs.dart` - `OmnistashTabs`: `TabBar`/`TabBarView` с четырьмя
  вкладками в порядке `TAB_RU` из `ui_src/app.js:5739` (Библиотека,
  Синхронизация, Очередь, Настройки; динамические вкладки площадок
  `platform` - не часть основной панели, это названо в
  `tools/check_flutter_mirror.py`). Первая вкладка - построенный
  `LibraryHome`; остальные - `StubPanel`, каждая называет, какой экран не
  построен и на какой волне ложится («не построенный экран, а не пустая
  очередь/журнал») - молчания нет.
- `lib/library_view.dart` - сортировка колонок: `kSortableColumns` - тот же
  порядок, подписи, ключи и гейты, что `LIST_COLS` в `ui_src/app.js:3170`
  (колонка `check` без sortable исключена из сверки - названо); ключи
  совпадают с белым списком сервера `ORDER_COLS` из `app/repo.py`; гейты
  `col_*` и ключи сохранения `sort_col`/`sort_dir` существуют в схеме
  настроек. Тогл - поведение `toggleSort` (`app.js:3256`): та же колонка
  разворачивает направление, новая начинает с `desc`, первая страница
  перезагружается; сохранённый порядок из снимка `get_initial` применяется
  тем же перезагрузочным правилом (`syncSortAndCols`, `app.js:3273`).
  Аргумент `order` - форма `ensureRange` (`app.js:3308`): ключ присутствует
  всегда, `null` при пустой колонке - сервер держит `uploaded_at DESC`.
  Отказ `save_setting` (403 по скоупу или поле `error` внутри 200)
  называется текстом, локальный порядок остаётся применённым к запросу.
- Семантика шапки колонки: флаг `header` внутри child кнопки сливается с
  узлом `TextButton` в один узел `[isButton, isHeader]` - эквивалент
  `role="columnheader"` на ячейке из `renderGridHead`; отдельного флага
  `aria-sort` в семантике Flutter нет (`SemanticsSortKey` задаёт только
  порядок обхода), направление передаётся текстом подписи со стрелкой ▲/▼ -
  названо расхождением. Обёртка `Semantics(container)` снаружи давала бы
  отдельный узел без кнопки - проверено зондом и widget-тестом.
- `test/fake_facade.dart` - подмена фасада пишет проводку: аргумент `order`
  каждого `list_videos` и ключ/значение каждого `save_setting` - тесты
  сверяют запросы клиента, а не «по ощущению».
- `test/library_view_test.dart` - 14 проверок экрана (прежние 9 + сортировка
  с тоглом и перезагрузкой, начальный порядок из `get_initial`, гейт
  `col_views`, отказ сохранения назван обеими формами, header-роль
  колонки); `test/tabs_test.dart` - 2 проверки табов (порядок подписей и
  selected активной вкладки через `flagsCollection`; заглушки называют
  волну и не притворяются пустым экраном).
- `main.dart` и `lib/app.dart` - без `OMNISTASH_SPIKE` экран теперь табы с
  библиотекой поверх фасада; снимок настроек целиком передаётся вкладкам
  (гейты колонок и порядок), при подмене фасада в тесте перечитывается.

`flutter analyze` - No issues found; `flutter test` - All tests passed
(25 проверок: 14 экран библиотеки, 2 табы, 8 токены темы, 1 смоук стенда);
`flutter build windows --release` - 39.0 с. Экран с табами сверен против
живого `--serve` (`python build/scratch/spike/live_serve.py --production`):
процесс живёт 3 с, сводку `SPIKE_STATS` печатает только стенд, журнал
аудита пишет те же методы с кодом 200 и правом `read`
(`get_initial`, `list_videos`, `poll` - табы не добавляют целей серверу).

Полный грид ячеек строк с колонками («Дата», «Просмотры», «Размер» и
остальные сейчас не рисуются - шапка управляет только порядком, названо
расхождением), карточка видео и диалоги (стек диалогов, ловушка Tab,
Escape, возврат фокуса, дефолт-отказ), чипы-фильтры, панель мультивыбора,
очередь и журнал как панели - следующие шаги W2 по
`docs/DESIGN-UI.md §3.8`.

Что сознательно НЕ перенесено и названо причиной: строки `box-shadow` и кольцо
фокуса (`--shadow`, `--shadow-1/2`, `--veil`, `--focus-ring`) - Flutter
строит elevation и фокус своими объектами, «строка-в-строку» не переносится,
форма тени ложится на волне W3; шрифты Raven-сабсетов (Roboto - Apache-2.0,
Instrument Sans / Bricolage Grotesque / JetBrains Mono - SIL OFL 1.1) -
только после аудита лицензии и пина по sha256 (`docs/LEGAL-REVIEW.md §5
«Отложить»`), до аудита Flutter держит системный стек и ничего не качает;
`--nums`, `--mono` и `--font-family` - не числа, они ложатся вместе со
шрифтом.

**Сборка и запуск (тулчейн ставится при сборке, рантайм ничего не качает):**

```powershell
$env:Path = "D:\dev\flutter\bin;$env:Path"   # SDK пинится в tools/flutter_pin.json
cd ui_flutter
flutter pub get
flutter analyze
flutter test
flutter build windows --release               # артефакт build\windows\x64\runner\Release\omnistash_ui.exe
```

Стенд замера требует запущенного слушателя: `python build/scratch/spike/mock_api.py`
(проводка контракта и TLS) или `python build/scratch/spike/live_serve.py`
(настоящий `app.http.server.ServeServer`, права решает сервер).

**Юр-часть:** Flutter engine и framework (BSD-3-Clause), Dart SDK
(BSD-3-Clause) и пакет `crypto` (BSD-3-Clause) используются при сборке. Их
тексты лицензий кладутся в `licenses/manifest.json` и `THIRD_PARTY_NOTICES.md`
на волне W5 - вместе с артефактами Flutter: текущая карта описывает бандл exe,
а Flutter в него ещё не входит. Рантайм по-прежнему не скачивает ничего:
SDK и pub-пакеты нужны только при сборке и закреплены версией, sha256 архива
SDK и `pubspec.lock`.
